# A 5-second token creates a 1-hour lease; when the token expires, the lease goes with it

$ BAO_TOKEN=<5-second token> bao write -field=lease_id pki/issue/agent common_name=agent.example.test ttl=1h
pki/issue/agent/<id>
exit_code=0

Leases under pki/issue/agent before the token expires: 1
